# VayuSenseX — Scientific Data Provenance & Integrity Audit

## 1. Data Provenance Hierarchy

Every metric displayed or computed within VayuSenseX is tagged with an explicit scientific data provenance level:

```
[OBSERVED / SENSOR]  ──> Ground-truth surface station telemetry (CPCB / CAAQMS stations)
[FORECAST]           ──> Numerical weather & atmospheric dispersion models (Copernicus CAMS, Open-Meteo Ensemble)
[CALCULATED]         ──> Pure deterministic mathematical functions (AQI breakpoints, EPA dose, mass-balance ODE)
[ESTIMATED]          ──> Peer-reviewed parametric factors (microclimate multipliers, cabin penetration, emission factors)
[ILLUSTRATIVE]       ──> Calibrated offline demonstration profiles (Sharma Family benchmark, Delhi winter smog archetype)
```

## 3. Anti-Hallucination Fact Registry

To eliminate AI hallucinations, the platform construct a runtime **Fact Registry** containing verified numeric values generated by the deterministic engines:
1. Every numerical claim generated by the assistant is cross-referenced against the registry.
2. A strict $\pm 5\%$ mathematical tolerance is enforced.
3. If an unrecognized Fact ID or out-of-tolerance number is detected, the response is rejected and replaced with verified deterministic guidance.
