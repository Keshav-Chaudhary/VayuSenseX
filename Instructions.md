## 🤖 AI Code Evaluation Criteria

Your code submission is automatically evaluated by AI against the following parameters:

1. **Code Quality:** Readability, structure, documentation, and maintainability.
2. **Security:** Secure coding practices, vulnerability avoidance, secret handling.
3. **Efficiency:** Performance, computational complexity, resource usage.
4. **Testing:** Unit/integration tests coverage and test robustness.
5. **Accessibility:** Standards adherence (e.g., WCAG, ARIA labels, semantic markup).
6. **Problem Statement Alignment:** How accurately and completely the solution fulfills the requirements.
