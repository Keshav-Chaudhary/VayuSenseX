# VayuSenseX — Automated Testing & Verification

VayuSenseX runs a multi-layered Vitest verification suite (**922 automated tests across 32 test files, 100% passing**) across domain math, API security, SSR landmarks, and interactive JSDOM user events:

- **Run all tests:** `npm test`
- **Run coverage:** `npm run test:coverage`
- **Run static lint:** `npm run lint`
- **Run strict typecheck:** `npm run typecheck`

See full suite matrix and coverage report: [docs/TESTING.md](docs/TESTING.md).
